# 👩‍🍳🍽️ Si Chef! – Frontend

**Si Chef!** es una plataforma colaborativa creada como proyecto final grupal de la carrera **Full Stack Developer en Henry**.  
La aplicación utiliza la cocina como excusa para conectar personas, compartir recetas y construir una comunidad activa donde el conocimiento gastronómico se desarrolla de manera colaborativa.

Este repositorio contiene el **frontend** de la aplicación.

---

## 🚀 Deploy

La aplicación se encuentra desplegada y lista para ser probada:

🔗 **URL de producción**  
https://si-chef.vercel.app/guest

---

## 🎨 Tecnologías utilizadas

- **Next.js**
- **React**
- **Tailwind CSS**
- **Fetch API** (consumo del backend)
- **NextAuth** (OAuth)
- **Socket.IO Client**
- **Stripe**

---

## ▶️ Ejecución del proyecto en desarrollo

```bash
# Clonar el repositorio
git clone <URL_DEL_REPOSITORIO_FRONTEND>

# Instalar dependencias
npm install

# Levantar el proyecto en modo desarrollo
npm run dev
```

## ✨ Funcionalidades principales

Autenticación de usuarios mediante OAuth

- **Visualización, creación y gestión de recetas**

- **Interfaz responsive y accesible**

- **Pagos integrados con Stripe**

- **Comunicación en tiempo real**

- **Manejo de sesiones con NextAuth**
